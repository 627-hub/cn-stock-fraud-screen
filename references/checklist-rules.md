# 财报排雷检查规则 (Minesweeper Checklist Rules)

本文档定义 40 条排雷规则的详细阈值、数据字段映射和评估逻辑（原版 32 条 + 本地增补 Rule 4.6 / 5.10 / 3.6 / 5.11 / 5.12 / 3.7 / 5.13 / 5.14）。
供 SKILL.md 在执行规则检查阶段参照。数据获取不走 Tushare：三表科目来自 a-stock-data skill 的新浪财报三表（§6.4），定性科目来自年报 PDF（用户已有财报下载 skill）或巨潮公告。

---

## 判定标准

每条规则返回以下四种判定之一：

- **PASS**: 未发现异常
- **WARN**: 轻微异常或边界信号（计入 WARN 分数）
- **FAIL**: 显著异常（计入 FAIL 分数）
- **SKIP**: 数据不足，标注原因

---

## Layer 0: 门槛检查（一票否决）

### Rule 0.1 — 审计意见

- **所需数据**: 最新年报审计意见与事务所名称（年报 PDF 审计报告页；或巨潮公告检索“审计报告”）
- **PASS**: `audit_result` 包含 "标准无保留" 或 "无保留意见"（且不含"保留"以外的修饰词）
- **FAIL**: 任何其他意见类型 → 风险等级直接定为"直接排除"
- **SKIP**: 审计数据为空

### Rule 0.2 — 按时披露

- **所需数据**: 年报公告日期与报告期截止日（巨潮公告列表中标题含“年度报告”且报告期为 12-31 的那条的公告日期）
- **逻辑**: 年报的 `end_date` 为 YYYYMMDD 格式（如 20241231），`ann_date` 是公告日期
- **PASS**: `ann_date` 在次年 4 月 30 日之前（即 end_date 年份 +1 年的 0430）
- **FAIL**: `ann_date` 超过截止日
- **SKIP**: `ann_date` 缺失

## Layer 1: 利润表信号

### Rule 1.1 — 毛利率异常高 + 大幅波动

- **所需数据**: 毛利率（利润表: 营业收入、营业成本，毛利率 = (营收-营业成本)/营收）。同行中位数无便捷来源时按“无同行数据”处理
- **计算**:
  - `gm_current` = 最新年度毛利率
  - `gm_prev` = 上一年度毛利率
  - `gm_yoy_change` = `gm_current - gm_prev`（单位: 百分点 pp）
  - `peer_median_gm` = 同行毛利率中位数
  - `gm_vs_peer` = `gm_current - peer_median_gm`
- **PASS**: `|gm_yoy_change| <= 5pp` 且 `gm_vs_peer <= 15pp`（或无同行数据）
- **WARN**: `|gm_yoy_change| > 5pp` 或 `gm_vs_peer > 15pp`
- **FAIL**: `|gm_yoy_change| > 10pp` 且 `gm_vs_peer > 15pp`
- **说明**: 如果无同行数据，仅用 YoY 波动判断

### Rule 1.2 — 毛利率↑ + 应收↑ + 应付↓

- **所需数据**: 毛利率（利润表）、应收账款与应付账款（资产负债表）、营业收入（利润表）
- **计算**:
  - 条件 A: 毛利率 YoY 上升
  - 条件 B: 应收账款增速 > 营收增速
  - 条件 C: 应付账款 YoY 减少
- **PASS**: 不满足任何条件，或仅满足 1 个条件
- **WARN**: 满足 2 个条件
- **FAIL**: 3 个条件同时满足

### Rule 1.3 — 运费增长 << 收入增长

- **数据源**: PDF 年报附注（三表无此科目）
- **指引**: 在附注的"销售费用"或"营业成本"明细中查找"运输费"/"运费"/"装卸费"
- **PASS**: 运费增速 >= 收入增速的 50%
- **WARN**: 运费增速 < 收入增速的 50%
- **FAIL**: 运费增速 < 收入增速的 25%
- **SKIP**: 运费数据未在附注中单独披露

### Rule 1.4 — 其他业务收入占比突增

- **所需数据**: 其他业务收入、营业收入（利润表；若数据源无“其他业务收入”单独科目则 SKIP）
- **计算**:
  - `ratio` = `oth_biz_income / revenue * 100`
  - `ratio_prev` = 上一年度同比
  - `ratio_change` = `ratio - ratio_prev`
- **PASS**: `ratio <= 5%` 或 `ratio_change <= 3pp`
- **WARN**: `ratio > 5%` 且 `ratio_change > 3pp`
- **FAIL**: `ratio > 15%` 或 `ratio_change > 10pp`

### Rule 1.5 — 费用率异常下降

- **所需数据**: 销售费用、管理费用、财务费用、营业收入（利润表）
- **计算**:
  - `expense_ratio` = `(sell_exp + admin_exp + fin_exp) / revenue * 100`
  - `avg_3yr` = 近 3 年费用率均值
  - `drop` = `avg_3yr - expense_ratio_current`
- **PASS**: `drop <= 3pp`
- **WARN**: `drop > 3pp` 或 费用率显著低于同行中位数
- **FAIL**: `drop > 5pp`

### Rule 1.6 — 资产减值损失暴增

- **所需数据**: 资产减值损失、信用减值损失、归母净利润（利润表）
- **计算**:
  - `total_impair` = `|assets_impair_loss| + |credit_impa_loss|`（注意减值可能为负数表示损失）
  - `impair_yoy` = YoY 变动百分比
  - `impair_to_profit` = `total_impair / |n_income_attr_p| * 100`
- **PASS**: `impair_yoy <= 50%` 且 `impair_to_profit <= 5%`
- **WARN**: `impair_yoy > 50%`
- **FAIL**: `impair_yoy > 100%` 或 `impair_to_profit > 5%`

## Layer 2: 现金流信号

### Rule 2.1 — 经营 CF 优异 + 投资 CF 持续大额为负

- **所需数据**: 经营活动现金流净额、投资活动现金流净额（现金流量表，取 5-10 个年报期）
- **计算**:
  - 逐年检查: `n_cashflow_act > 0` 且 `|n_cashflow_inv_act| > n_cashflow_act * 0.8`
  - 统计满足条件的年数
- **PASS**: 满足条件的年数 <= 1
- **WARN**: 满足条件的年数 = 2-3
- **FAIL**: 满足条件的年数 >= 4，且投资 CF 绝对值持续大于经营 CF
- **说明**: 正常扩张企业投资 CF 为负是正常的，但如果持续大幅超过经营 CF 需要警惕

### Rule 2.2 — 经营 CF 持续为负

- **所需数据**: 经营活动现金流净额（现金流量表，取 5-10 个年报期）
- **计算**: 统计 `n_cashflow_act < 0` 的年数和连续为负的最长年数
- **PASS**: 近 5 年中为负的年数 <= 1
- **WARN**: 近 5 年中 2 年为负
- **FAIL**: 连续 3+ 年为负

### Rule 2.3 — 高现金 + 高息借债

- **所需数据**: 货币资金、短期借款、长期借款、应付债券（资产负债表）+ 财务费用（利润表）
- **计算**:
  - `interest_bearing_debt` = `st_borr + lt_borr + bond_payable`（取最新期）
  - `cash` = `money_cap`
  - `implied_rate` = `|fin_exp| / interest_bearing_debt * 100`（粗估利率）
  - 基准利率参考: 约 3-4%（当前 LPR 水平）
- **PASS**: `cash < interest_bearing_debt * 0.5` 或 `implied_rate <= 基准 + 2pp`
- **WARN**: `cash > interest_bearing_debt * 0.5` 且 `implied_rate > 基准 + 2pp`
- **FAIL**: `cash > interest_bearing_debt` 且 `implied_rate > 基准 + 4pp`
- **说明**: 账上大量现金却高息借债 = 经典造假信号，现金可能是假的

## Layer 3: 资产负债表信号

### Rule 3.1 — 应收增速 > 收入增速

- **所需数据**: 应收账款（资产负债表）、营业收入（利润表）
- **计算**:
  - `ar_growth` = 应收账款 YoY 增速
  - `rev_growth` = 营收 YoY 增速
  - `ratio` = `ar_growth / rev_growth`（当 rev_growth > 0 时）
- **PASS**: `ratio <= 1.5` 或应收账款金额很小（< 营收 5%）
- **WARN**: `ratio > 1.5`
- **FAIL**: `ratio > 2.0`
- **边界**: 如果营收下降但应收增长，直接 WARN

### Rule 3.2 — 存货周转率↓ + 毛利率↑（大概率造假组合信号）

- **所需数据**: 存货周转率 = 营业成本/平均存货、毛利率（三表计算）
- **计算**:
  - `inv_turn_change` = 存货周转率 YoY 变化百分比
  - `gm_change` = 毛利率 YoY 变化（pp）
- **PASS**: 不满足组合条件
- **WARN**: `inv_turn_change < -10%` 且 `gm_change > 0`
- **FAIL**: `inv_turn_change < -20%` 且 `gm_change > 3pp`
- **特殊**: 此规则 FAIL 时触发组合加分 +10

### Rule 3.3 — 在建工程不转固

- **所需数据**: 在建工程、固定资产（资产负债表，取 3-5 个年报期）
- **计算**:
  - 逐年检查: CIP 增长 >30% 但固定资产未相应增长
  - 统计持续增长年数
- **PASS**: CIP 不存在或未持续增长
- **WARN**: CIP 增长 >30% 且固定资产增长率 < CIP 增长率的 50%
- **FAIL**: 上述情况持续 3+ 年

### Rule 3.4 — 长期待摊费用大增

- **所需数据**: 长期待摊费用、总资产（资产负债表）
- **计算**: `yoy_change` = YoY 变动百分比
- **PASS**: `yoy_change <= 50%` 或金额很小（< 总资产 1%）
- **WARN**: `yoy_change > 50%`
- **FAIL**: `yoy_change > 100%`

### Rule 3.5 — 坏账计提比例低于同行

- **所需数据**: 应收账款（资产负债表）、信用减值损失（利润表）；同行数据不足则 SKIP
- **计算**:
  - `bad_debt_ratio` = `|credit_impa_loss| / accounts_receiv * 100`
  - 与同行对比（使用同行的 ar_turn 作为代理指标）
- **PASS**: 比例不显著低于同行
- **WARN**: 比例低于同行中位数
- **FAIL**: 比例低于同行中位数 50%
- **SKIP**: 如果应收账款极小或同行数据不足

### Rule 3.6 — 预付款项异常（资金转移通道）（增补）

- **所需数据**: 预付款项、总资产（资产负债表）、营业收入（利润表），取 3-5 个年报期；PDF 附注"预付款项"账龄明细（如有）
- **计算**:
  - `ratio` = 预付款项 / 营业收入 × 100
  - `ratio_ta` = 预付款项 / 总资产 × 100
  - `yoy_change` = 预付款项 YoY 变动百分比
  - `aging_1y_plus` = 附注中账龄 1 年以上预付款占比（如披露）
- **PASS**: `ratio <= 10%`（或 `ratio_ta <= 3%`）且 `yoy_change <= 50%`
- **WARN**: `ratio > 10%` 且 `yoy_change > 50%`；或 `aging_1y_plus > 30%`
- **FAIL**: `ratio > 20%` 且 `yoy_change > 100%` 连续 2+ 年；或 `aging_1y_plus > 50%`
- **SKIP**: 科目缺失
- **说明**: 正常采购预付周期短，预付/营收通常 <10%。大额、暴增、长期挂账的预付款是资金转移与体外循环的经典通道——付给难以核实的第三方，实质可能是借款或占用。账龄 1 年以上仍未交货 = 钱基本要不回来/不是真采购。


### Rule 3.7 — 渠道压货信号（合同负债背离 + 渠道定性）（增补）

- **所需数据**: 合同负债、预收款项、应收票据、营业收入（三表，取 3-5 个年报期）；PDF"销售模式/经销商"章节（经销商数量、退网、退货政策）；互动易问答（可选，a-stock-data §10.1）
- **计算**:
  - `cl_ratio` = (合同负债 + 预收款项) / 营业收入 × 100
  - 条件 A: 营收增长 但 合同负债+预收 连续 2 年下滑 >20%（渠道打款意愿退坡）
  - 条件 B: (应收票据+应收账款) 增速 > 营收增速 × 2（压货常走票据，补充 3.1）
  - 条件 C: 收现比同步走弱（与 4.2 联动）
- **PASS**: `cl_ratio` 稳定或随营收同向变化；或 `cl_ratio < 1%` 且票据规模极小（无预收模式）
- **WARN**: 满足条件 A 或 B 单项
- **FAIL**: 条件 A + C 同时满足 → 典型压货后收入断档前兆
- **SKIP**: 无预收模式且票据规模极小
- **说明**: 压货 = 向渠道塞库存换当期收入。报表痕迹是经销商不再打款（合同负债萎缩）与赊销比例上升。铁证仍需渠道调研/退货率——定性部分查 PDF 经销商数量与退网变化、互动易里投资者关于库存的问答。

## Layer 4: 交叉验证（权重最高）

### Rule 4.1 — 经营 CF / 净利润 < 1

- **所需数据**: 经营活动现金流净额（现金流量表）、归母净利润（利润表），取 5+ 个年报期
- **计算**:
  - 逐年: `cf_to_profit` = `n_cashflow_act / n_income_attr_p`（当净利润 > 0）
  - 统计 `cf_to_profit < 1` 的年数
- **PASS**: 近 5 年中仅 0-1 年 < 1
- **WARN**: 近 5 年中 2 年 < 1
- **FAIL**: 连续 3+ 年 < 1
- **说明**: 这是最核心的验证。优秀企业此比值持续 > 1

### Rule 4.2 — 销售收现 / 营收 < 1

- **所需数据**: 销售商品、提供劳务收到的现金（现金流量表）、营业收入（利润表）
- **计算**:
  - `cash_to_rev` = `c_recp_prov_sg_act / (revenue * 1.13)`
    （含增值税调整，A股一般税率 13%，实际应根据行业调整）
  - 简化版: `c_recp_prov_sg_act / revenue`（不含税调整，阈值相应调低）
- **PASS**: `cash_to_rev >= 0.9`（持续多年）
- **WARN**: `cash_to_rev < 0.9`
- **FAIL**: `cash_to_rev < 0.8` 持续 2+ 年

### Rule 4.3 — 利润膨胀 → 资产膨胀

- **所需数据**: 营业收入、归母净利润（利润表）、总资产（资产负债表）
- **计算**:
  - `asset_growth` = 总资产 YoY 增速
  - `rev_growth` = 营收 YoY 增速
  - `profit_growth` = 净利润 YoY 增速
  - 异常信号: 资产增速 >> 营收增速，且利润增长
- **PASS**: `asset_growth <= rev_growth * 1.5` 或利润未增长
- **WARN**: `asset_growth > rev_growth * 2` 且利润增长
- **FAIL**: `asset_growth > rev_growth * 3` 且利润增长，连续 2+ 年

### Rule 4.4 — 核心利润 vs 净利润背离

- **所需数据**: 营业收入、营业成本、销售费用、管理费用、财务费用、归母净利润（利润表）
- **计算**:
  - `core_profit` = `revenue - oper_cost - sell_exp - admin_exp - fin_exp`
  - `divergence` = `|core_profit - n_income_attr_p| / |n_income_attr_p| * 100`
- **PASS**: `divergence <= 20%`
- **WARN**: `divergence > 20%`
- **FAIL**: `divergence > 40%`
- **说明**: 大幅背离说明利润主要来自非经营性因素

### Rule 4.5 — 净利润增长 + FCF 持续为负

- **所需数据**: 归母净利润（利润表）；FCF = 经营活动现金流净额 - 购建固定资产、无形资产和其他长期资产支付的现金（现金流量表）
- **计算**:
  - 逐年检查: 净利润 > 0 且增长，但 FCF < 0
  - 统计满足条件的年数
- **PASS**: 满足条件 0-1 年
- **WARN**: 满足条件 2 年
- **FAIL**: 满足条件 3+ 年

---


### Rule 4.6 — 少数股东权益占比 vs 损益占比背离（明股实债/利润转移）（增补）

- **所需数据**: 少数股东权益、所有者权益合计（资产负债表）；少数股东损益、净利润（利润表），取 3 个年报期
- **计算**:
  - `eq_ratio` = 少数股东权益 / 所有者权益合计 × 100
  - `pnl_ratio` = 少数股东损益 / 净利润 × 100（净利润与少数股东损益同号时比值仍有效）
  - 逐年观察近 3 个年报期
- **PASS**: `eq_ratio < 5%`（少数股东权益规模不显著，无判断意义）或 `pnl_ratio >= eq_ratio * 0.5`
- **WARN**: `eq_ratio >= 10%` 且 `pnl_ratio < eq_ratio * 0.3` 连续 2 年；或少数股东权益 YoY 暴增 >100% 且历史损益贡献长期≈0
- **FAIL**: `eq_ratio >= 20%` 且（`pnl_ratio < 5%` 或 少数股东损益为负）连续 2+ 年 → 少数股东"持股却长期分不到钱"
- **SKIP**: 少数股东权益科目缺失
- **说明**: 持股比例与损益分配长期不匹配的两种解释：(a) 明股实债——"股权"实为固定回报融资，回报走利息/其他科目；(b) 归母方通过关联交易、费用分摊转移子公司利润以虚增归母业绩。两者均为红旗。佐证指标: 少数股东ROE（少数股东损益/平均少数股东权益）长期≈0 或大幅低于归母ROE。

## Layer 5: 非财务信号

### Rule 5.1 — 更换审计机构

- **所需数据**: 多年审计机构名称（各年年报 PDF 审计报告页签字事务所；或巨潮检索各年“审计报告”公告）
- **计算**: 比较各年度的事务所名称是否变化
- **PASS**: 连续多年使用同一家事务所
- **WARN**: 更换过 1 次
- **FAIL**: 更换过 2 次及以上

### Rule 5.2 — 大股东减持

- **所需数据**: 控股股东/第一大股东持股比例（年报 PDF“前十名股东”表，取最近 2-3 个年报期）
- **计算**: 比较第一大股东（或控股股东）在不同报告期的 hold_ratio
- **PASS**: 持股比例稳定或增加
- **WARN**: 持股比例连续下降
- **FAIL**: 持股比例大幅下降（>5pp）
- **SKIP**: 股东数据不足

### Rule 5.3 — 财务总监频繁更换

- **数据源**: PDF 年报"董事、监事、高级管理人员"章节
- **指引**: 搜索"财务总监"/"首席财务官"/"CFO"，查看是否标注"本年离任"
- **PASS**: 无异常变动
- **WARN**: 本年有 CFO 变更
- **FAIL**: 近 2-3 年多次变更
- **SKIP**: 无法从当期年报判断

### Rule 5.4 — 独董集体辞职

- **数据源**: PDF 年报"董事、监事、高级管理人员"章节
- **指引**: 搜索"独立董事"，查看是否有多名标注"辞职"
- **PASS**: 无异常
- **WARN**: 1 名独董辞职
- **FAIL**: 2 名及以上独董同期辞职
- **SKIP**: 无法从当期年报判断

### Rule 5.5 — 可疑供应商/客户

- **数据源**: PDF 附注"前五名客户"/"前五名供应商"
- **指引**: 读附注中对应表格
- **PASS**: 前 5 大客户合计占比 < 30%，且客户名称正常
- **WARN**: 前 5 大客户合计占比 > 50%，或客户为不透明实体
- **FAIL**: 单一客户占比 > 50%

### Rule 5.6 — 跨行业频繁收购

- **数据源**: PDF 董事会报告"投资状况分析"
- **指引**: 读董事会报告中的投资/收购部分
- **PASS**: 无跨行业收购或仅有 1 次相关行业收购
- **WARN**: 有跨行业收购
- **FAIL**: 多次跨行业收购

### Rule 5.7 — 商誉过大

- **所需数据**: 商誉、归属于母公司所有者权益（资产负债表）
- **计算**: `goodwill_ratio` = `goodwill / total_hldr_eqy_exc_min_int * 100`
- **PASS**: `goodwill_ratio <= 20%` 或 goodwill 为 0/null
- **WARN**: `goodwill_ratio > 20%`
- **FAIL**: `goodwill_ratio > 40%`

### Rule 5.8 — 其他应收款异常

- **所需数据**: 其他应收款、总资产（资产负债表）+ PDF 年报
- **计算**:
  - `ratio` = `oth_receiv / total_assets * 100`
  - `yoy_change` = 其他应收款 YoY 变动百分比
- **PASS**: `ratio <= 3%` 且 `yoy_change <= 30%`
- **WARN**: `ratio > 3%` 或 `yoy_change > 30%`
- **FAIL**: `ratio > 5%` 或 `yoy_change > 50%`
- **补充检查** (PDF): 在年报全文中搜索 "非经营性占用" — 如果该段落标注 "适用"，直接 FAIL
- **说明**: 其他应收款是关联方资金占用的常见藏身之处。大额其他应收款 + 关联方往来 = 经典资金占用信号

### Rule 5.9 — 监管处罚/立案调查

- **数据源**: PDF 年报全文
- **指引**: 在年报文本中搜索以下关键词: `立案`, `警示函`, `处罚决定`, `监管措施`, `行政处罚`, `纪律处分`, `通报批评`, `公开谴责`
- **判断**:
  - 匹配后读取上下文，区分以下情况:
    - A. 公司/控股股东/实控人被立案调查 → FAIL
    - B. 公司/董监高收到警示函或行政处罚 → WARN
    - C. 仅涉及一般性合规整改、环保罚款等 → PASS
    - D. 搜索无匹配 → PASS
- **说明**: 监管处罚和立案调查是重大风险前兆。喜临门案例: 2024年报已披露证监局警示函(2023)和上交所口头警示(2024)，但公司后续被发现存在多年资金占用黑幕

### Rule 5.10 — 明股实债定性信号（增补）

- **所需数据**: PDF 年报全文 + 资产负债表"其他权益工具"科目
- **指引**: 全文搜索关键词: `回购`, `差额补足`, `固定收益`, `保底`, `对赌`, `业绩承诺补偿`, `到期回购`, `名股实债`, `永续债`, `结构化主体`, `资管计划`, `信托计划`; 并检查资产负债表"其他权益工具（永续债/优先股）"余额
- **判断**:
  - A. 披露股权回购/差额补足/固定收益承诺且金额重大 → FAIL
  - B. 其他权益工具（永续债）余额 > 归母权益 10% → WARN（永续债计权益但带固定票息与利率跳升条款，实质是高息债）
  - C. 仅有正常并购业绩承诺/对赌安排 → PASS 或视规模 WARN
  - D. 无匹配 → PASS
- **说明**: 明股实债的常见外衣：子公司引入"战投"附回购条款、员工持股平台固定回报、永续债、并表结构化主体。量化佐证见 Rule 4.6。


### Rule 5.11 — 大股东高比例质押（增补）

- **所需数据**: 控股股东质押股数与其持股总数（年报 PDF"前十名股东"表"质押、标记或冻结情况"列；或东财/F10 质押数据）
- **计算**: `pledge_ratio` = 控股股东质押股数 / 其持股总数 × 100
- **PASS**: `pledge_ratio < 10%` 或无质押
- **WARN**: `10% <= pledge_ratio <= 50%`
- **FAIL**: `pledge_ratio > 50%`（尤其连续多期高企或上升趋势）
- **SKIP**: 股东表未披露质押明细
- **说明**: 高质押 = 大股东资金饥渴，是资金占用、违规担保、易主风险的前兆；与 Rule 5.2 减持、Rule 5.8 其他应收款组合出现时危险度倍增。爆仓强平还会引发控制权不稳定。


### Rule 5.12 — 客户与供应商重叠勾稽（循环交易/round-trip）（增补）

- **所需数据**: PDF 年报附注"前五名客户"与"前五名供应商"名称明细（部分公司匿名化披露则无法核对）+ 关联方关系附注
- **指引**: 交叉比对前五客户与前五供应商名单；对重叠/相近名称追查工商关联（同一实控人、注册地相近、名称近似壳公司）
- **PASS**: 无重叠，或重叠方属正常双向业务（加工返料、贸易商双向采购销售等）
- **WARN**: 前五客户与前五供应商出现同一名实体且双向金额重大
- **FAIL**: 重叠方为疑似关联方/新设实体，双向金额重大 → 典型收入成本对倒（round-trip 虚增收入）
- **SKIP**: 附注未披露名称（A股常见"客户1/供应商1"匿名化）
- **说明**: 同一实体既是客户又是供应商 = 收入与成本闭环对倒，浑水 Sino-Forest 报告的核心手法。注意保留合法双向业务的例外。


### Rule 5.13 — 财务造假前科与重述历史（增补）

- **所需数据**: 巨潮公告全历史检索（用 §7.1 hisAnnouncement/query 接口带 searchkey，该接口按股票过滤有效；**勿用 fulltextSearch 接口——其不过滤单票**）+ PDF"重要前期差错更正"附注
- **检索关键词**: `立案`, `行政处罚`, `警示函`, `监管关注`, `纪律处分`, `公开谴责`, `更正`, `会计差错更正`, `追溯调整`, `前期差错`, `虚假记载`, `资金占用`
- **判断**:
  - A. 曾被行政处罚且涉及虚假记载/虚增收入利润/资金占用 → WARN（5 年内）；2 次及以上或近 3 年内 → FAIL
  - B. 有重大会计差错更正/追溯重述 → WARN；2 次以上 → FAIL
  - C. 仅警示函/监管关注 → 累计 ≥2 次 WARN，否则 PASS
  - D. 无记录 → PASS
- **SKIP**: 巨潮检索不可用
- **说明**: 重犯率是舞弊预测最强的单变量之一（有舞弊前科公司再犯率数倍于基线），唐朝方法论"有前科直接拉黑"。注意区分财务类处罚与环保/信披程序性瑕疵。


### Rule 5.14 — 股权结构复杂性/离岸架构（增补）

- **所需数据**: PDF"实际控制人"章节与股权结构图；十大股东表"股东性质"列
- **指引**: 检查控制链条: 境外注册控股实体（BVI/开曼/新加坡/香港 SPV）、控制层级 ≥4 层、一致行动人 ≥3 家、家族信托/资管计划嵌套、"无实际控制人"+股权分散
- **PASS**: 控制链条清晰（境内国资/产业资本/自然人直接持股）
- **WARN**: 含境外多层 SPV 或层级 ≥4；或"无实际控制人"且股权分散
- **FAIL**: 离岸复杂结构 与 任一财务红旗（Layer 2/3 FAIL）同时出现 → 结构性放大器
- **SKIP**: 股权结构图无法解析
- **说明**: 复杂架构本身不是造假证据，但它让审计与监管难以穿透——是舞弊的"放大器"而非"触发器"，故 FAIL 需与财务红旗组合。A股公司主体在境内，主要看控股股东层；VIE/中概架构不适用本 skill。

## Layer 6: 行业特有风险

### Rule 6.1 — 农林渔牧行业

- **所需数据**: 公司所属行业（a-stock-data skill 东财个股信息接口 / F10 公司资料）
- **高风险行业关键词**: 农业, 林业, 渔业, 牧业, 畜牧, 养殖, 种植, 饲料, 水产
- **PASS**: 不属于高风险行业
- **WARN**: 行业包含以上关键词
- **说明**: 生物资产难以审计，是历史上造假高发区

### Rule 6.2 — 研发资本化比例

- **数据源**: PDF 附注"研发支出"或"开发支出"
- **指引**: 在附注中搜索"研发支出"/"开发支出"/"资本化"
- **计算**: `cap_ratio` = 资本化金额 / (资本化金额 + 费用化金额) * 100
- **PASS**: `cap_ratio <= 30%` 或全部费用化
- **WARN**: `cap_ratio > 30%`
- **FAIL**: `cap_ratio > 50%`
- **SKIP**: 附注中无明确的资本化/费用化拆分
